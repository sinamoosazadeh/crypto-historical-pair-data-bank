# Governance

The project is maintainer-led while the dataset registry and tooling mature. Maintainers are responsible for merge decisions, release tagging, schema compatibility and resolving conflicting source evidence.

## Evidence-based decisions

- Prefer primary sources and exact artifacts.
- Keep observed facts distinct from interpretation.
- Record disputes and competing evidence rather than silently overwriting it.
- Version schema changes and document migration requirements.
- Never reject a correction solely because it conflicts with an existing claim; inspect evidence.

As the contributor base grows, this model can transition to a documented maintainer group and delegated ownership for exchanges, schemas, UI and tooling.
