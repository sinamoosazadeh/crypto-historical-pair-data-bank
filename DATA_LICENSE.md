# Data and metadata licensing policy

The MIT license in `LICENSE` applies to the project's original software code. It does **not** grant rights to exchange-owned data, third-party archives, logos, documentation, or any dataset merely linked by this repository.

Original descriptive metadata authored for this registry is intended to be shared under **CC BY 4.0** where legally applicable, subject to upstream terms, attribution requirements, and the rights of third parties. Each source entry must record its provenance and any known restrictions. If a provider's terms are unclear, mark the record `terms_review_required` and do not mirror raw files.

Before adding a raw or derived dataset, record:

- original provider and canonical URL;
- access method and whether registration, API key or payment is required;
- applicable license / terms URL and redistribution permission status;
- collection date/time in UTC, file size and SHA-256;
- transformations and schema version;
- whether the data contains personal, licensed, export-restricted or otherwise restricted information.

A direct download being reachable without login is not proof of permission to redistribute it. Prefer indexing upstream files over copying data into Git history. Never commit credentials, API keys, session cookies or private user data.
