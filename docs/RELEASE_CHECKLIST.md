# Release checklist

- [ ] CI succeeds on a clean checkout.
- [ ] Source registry validates and generated browser bundle matches canonical JSON.
- [ ] Every changed coverage assertion has a source URL and check date.
- [ ] No credentials, raw oversized archives or private data are included.
- [ ] Source terms have been reviewed or clearly marked unknown.
- [ ] Documentation and changelog updated.
- [ ] Schema breaking changes carry a version and migration note.
- [ ] ZIP/tarball and checksums verified when publishing assets.
- [ ] UI tested on desktop and narrow mobile layout; keyboard navigation and contrast checked.
- [ ] Release notes distinguish verified counts from estimated/expected buckets.
