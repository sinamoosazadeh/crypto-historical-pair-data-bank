Eligibility rule

Only promote a resource to “anonymous download verified” after testing the exact file without a login or API key, retaining the check time, HTTP result, artifact hash, schema and locally counted rows. Requester-pays paths, account gates, API-only endpoints and asset-level metrics are not equivalent to free exchange-pair candle archives.

CROSS-CHECKED

Completeness is multidimensional

Use precise, scoped claims

  • Venue + market: spot and perpetual contracts are not interchangeable.
  • Instrument: exact provider symbol and lifecycle are needed.
  • Interval: native support and anchor semantics must be documented.
  • Time range: archive naming is not proof all rows exist.
  • Rows vs buckets: a theoretical bucket count is not an observed candle count.
  • Missing bars: no trade, omitted empty bars, delisting and collection failure are distinct.

Reproducible workflow

Small steps; durable evidence

  1. Resolve venue, market, pair and interval.
  2. Inspect listing and canonical download path.
  3. Capture the check time in UTC and response metadata.
  4. Download within explicit size and retry limits.
  5. Hash the original artifact and inspect its schema.
  6. Count observed rows and parse timestamp units.
  7. Report gaps and licensing separately.
  8. Publish a versioned manifest and a repeatable command.
