# Security policy

This project is a public catalogue and local tooling repository. Do not submit API keys, access tokens, cookies, personal data or private exchange information in issues, pull requests, logs or example files.

For a suspected credential leak or security-sensitive report, do not open a public issue. Use GitHub's private vulnerability reporting if enabled, or contact the repository owner privately through GitHub.

Supported versions: the latest default branch. Security fixes are accepted for current scripts and UI. Reports should include affected path, impact, reproduction steps and a safe proof of concept without real credentials.
